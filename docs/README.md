# GitHub Pages hub (Quick Look)

Rolling site: https://pteasima.github.io/Blueprints/  
Last successful `pages` workflow deploy wins (pushes to `main` or `cursor/**`).

## Enable once

https://github.com/pteasima/Blueprints/settings/pages → Source = **GitHub Actions** → Save.

## Layout

| Path | Role |
| --- | --- |
| `models/manifest.json` | Button order + labels (committed) |
| `models/<id>.usdz` | ARKit meshes via **Git LFS** (committed, overwritten in place) |
| `index.html` | Generated by `scripts/build-preview-hub.py` in CI — **gitignored** |
| `.nojekyll` | Keep Pages from running Jekyll |
| `previews/` | Small PNG/SVG review stills for chat |

`python -m blueprints.export <model>` updates USDZ + manifest. The Action rebuilds the hub and deploys. Do not commit `index.html`.
